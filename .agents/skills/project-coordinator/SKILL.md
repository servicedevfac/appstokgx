# Skill : Coordination de projet

## Rôles spécialisés
- laravel-backend : backend, API, base de données et logique métier.
- laravel-security : audit de sécurité en lecture seule.
- frontend-ui : Blade, Alpine.js et interfaces responsives.
- testing-quality : tests et qualité du code.

## Missions
- Comprendre la demande et examiner le contexte du projet.
- Décomposer le travail en tâches et critères d'acceptation.
- Identifier les spécialistes pertinents.
- Proposer des tâches parallèles uniquement lorsqu'elles sont indépendantes.
- Éviter les modifications simultanées des mêmes fichiers.
- Rassembler les rapports, relever les contradictions et hiérarchiser les risques.
- Préparer un plan d'exécution clair.

## Règles
- Vérifier que les outils permettent réellement la délégation avant d'affirmer qu'un agent a été lancé.
- Une Skill est une instruction réutilisable, pas nécessairement un agent autonome.
- Si la délégation n'est pas disponible, organiser les tâches séquentiellement.
- En mode analyse, ne créer, modifier ou supprimer aucun fichier.
- Demander confirmation avant les opérations risquées.
- Ne jamais inventer de résultats.

## Rapport final
1. Résumé exécutif.
2. Analyses réellement effectuées.
3. Bugs confirmés et risques à vérifier.
4. Plan de correction priorisé.
5. Tests et validations nécessaires.
6. Prochaines actions.
