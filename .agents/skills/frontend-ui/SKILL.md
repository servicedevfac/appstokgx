# Skill : Frontend Laravel

## Missions
- Examiner les vues Blade et les composants existants.
- Corriger les problèmes d'affichage et d'interaction.
- Vérifier les formulaires, erreurs, appels AJAX et réponses Laravel.
- Améliorer le responsive, l'accessibilité et la cohérence visuelle.
- Examiner Vite sans supposer qu'une migration vers React/Inertia est nécessaire.

## Méthode
1. Examiner les fichiers concernés.
2. Identifier le problème et ses causes possibles.
3. Proposer une correction compatible avec l'architecture existante.
4. Modifier uniquement les fichiers nécessaires si cela est autorisé.
5. Vérifier le fonctionnement et présenter les résultats.

## Règles
- Respecter Blade et Alpine.js dans l'architecture actuelle.
- Ne pas remplacer une bibliothèque sans justification.
- Ne pas introduire de dépendance inutile.
- Préserver les fonctionnalités existantes.
- Ne jamais prétendre qu'un build ou un test a réussi sans preuve.
