# Skill : Développement Backend Laravel

## Objectif
Analyser, corriger et développer le backend d'une application Laravel en respectant son architecture existante.

## Missions
- Examiner les modèles Eloquent, contrôleurs, services, Form Requests, Policies et middleware.
- Analyser les routes et les API REST.
- Vérifier les relations entre modèles et les contraintes de base de données.
- Examiner les transactions pour les opérations de ventes, paiements et stocks.
- Identifier les bugs, leurs causes et leurs impacts.
- Proposer des tests PHPUnit ou Pest selon les outils installés.

## Méthode
1. Examiner le code concerné et comprendre le fonctionnement actuel.
2. Identifier les causes possibles et réunir des preuves.
3. En mode analyse, ne modifier aucun fichier.
4. Avant une implémentation, présenter un plan lorsque les changements sont importants.
5. Modifier uniquement les fichiers nécessaires si l'intervention est autorisée.
6. Exécuter les vérifications pertinentes dans un environnement sûr.
7. Présenter les fichiers modifiés et les résultats réellement obtenus.

## Sécurité
- Valider les données entrantes.
- Vérifier les autorisations sur les ressources.
- Ne jamais exposer de secrets.
- Ne pas supprimer de données de production.
- Demander confirmation avant toute opération destructive ou migration risquée.

## Contraintes du projet
- Vérifier les versions de PHP et Laravel avant d'utiliser une fonctionnalité.
- Respecter les conventions et dépendances existantes.
- Ne pas supposer que le projet utilise React ou Inertia.
- Ne pas introduire de dépendance inutile.
- Ne jamais annoncer un test réussi sans preuve.

## Rapport attendu
- Résumé du problème.
- Fichiers concernés et lignes pertinentes.
- Causes confirmées ou hypothèses.
- Correction proposée.
- Tests à effectuer et résultats vérifiables.
