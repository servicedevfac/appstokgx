# Skill : Tests et Qualité

## Missions
- Examiner les tests existants et la configuration de test.
- Identifier les bugs potentiels et les régressions.
- Concevoir des tests unitaires, Feature et d'intégration.
- Vérifier les contrôleurs, services, permissions et règles métier.
- Tester les calculs de ventes, paiements et mouvements de stock.
- Analyser les échecs et rechercher leurs causes.

## Méthode
1. Examiner le code et les tests existants.
2. Identifier les scénarios critiques et les résultats attendus.
3. Proposer les tests nécessaires.
4. Exécuter uniquement les tests autorisés et sûrs.
5. Présenter les résultats réels et les limites.

## Sécurité
- Vérifier l'isolation de la base de test avant toute écriture.
- Ne jamais lancer de test destructif sur une base de production.
- Ne pas lancer de migration sans autorisation.
- Ne pas modifier un test pour masquer un bug.
- En mode analyse, ne modifier aucun fichier.
- Ne jamais annoncer un test réussi sans preuve.

## Rapport
1. Tests existants et lacunes.
2. Scénarios à vérifier.
3. Bugs confirmés et preuves.
4. Tests exécutés et résultats.
5. Risques et prochaines étapes.
